# Sell Here QA Portfolio

## Overview

This repository contains my manual QA portfolio for **Sell Here**, a full-stack e-commerce web application.

The purpose of this portfolio is to demonstrate my practical manual testing skills by documenting test planning, test case design, bug reporting, regression testing, and verification of fixes performed during the development of the application.

## Application

**Sell Here** is an e-commerce web application featuring:

- User authentication
- Anonymous guest sessions
- Product browsing
- Product search
- Shopping cart
- Checkout
- User profile
- Responsive design
